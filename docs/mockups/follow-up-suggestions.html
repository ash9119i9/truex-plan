BAPI_SALESORDER_CREATEFROMDAT2 returns success but no order is created. Why?
SAP Assistant

The BAPI only stages the order in the update task. Nothing is written until you call BAPI_TRANSACTION_COMMIT in the same LUW, so a "success" RETURN without a commit leaves no document behind.

Also check RETURN for type E or A rows. A partner-function error (for example a missing ship-to) is reported there while SALESDOCUMENT stays empty.
