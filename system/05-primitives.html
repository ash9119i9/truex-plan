Before the first control

Four laws, one hand.

Nothing on this page is a matter of taste. Every size, gap, curve and colour is a consequence of how people point, choose, perceive motion and remember. Each law below is applied — and measured — further down.

  1. Math · the hand

    Fitts 1954

    MT = a + b · log₂(2D / W)

    Bigger, nearer targets are faster to hit. Height is latency — so the default cap is 36, the confirm cap is 44 and nothing drops under 24.

    Applied in 5.2 Keycaps
  2. Psychology · the choice

    Hick–Hyman 1952

    RT = a + b · log₂(n + 1)

    Each extra option costs time, but less than the last. Spend options like money: show two to four, hide the long tail in a menu.

    Applied in 5.4 Pickers
  3. Physics · the motion

    Damped spring Hooke

    x″ + 2ζω x′ + ω² x = 0

    Real things have mass and friction. A toggle may overshoot; a confirmation never does — a bounce on “Approve” reads as doubt.

    Applied in 5.7 Live
  4. Human nature · the eye

    Isolation von Restorff 1933

    1 differs of n ⇒ recalled

    The one that differs is the one that is found and remembered. One primary per surface; two equal primaries cancel each other out.

    Applied in 5.2 Keycaps

Also measured here Gestalt proximity, 4 : 16 · 5.5  /  Reading rate, 200 wpm · 5.6  /  Contrast, 4.5 : 1 · 5.3  /  Peak–end, the exit is the memory · 5.8

5.1

Grammar · affordance · curvature

Shape is a sentence.

A capsule says press. A squircle says hold. A circle says state. A 3px mark says measure. Before a single colour is added, the silhouette has already told the hand what can happen — and the eye what to trust.

Affordance · Gibson 1979 shape ⇒ verb

An object's form tells the body what it offers before the mind names it.

5.2

Keycaps · action

The next action, made physical.

A button is a keycap: a surface that promises travel. Four sizes, five variants, one primary. The label names the outcome; the shortcut rides on the cap; the halo arrives for the keyboard.

Fitts · 1954 MT = a + b · log₂(2D/W)

Time to hit a target grows with distance and shrinks with size. Every pixel of height is time returned.

5.3

Tokens · state · reference

Small things that mean something.

Pills name state, chips let you pick or point, tiles hold a glyph, keycaps name a key. Each has one job and one silhouette. Status never travels as colour alone.

Luminance, not hue, is what an ageing or colour-blind eye can still separate.

5.4

Pickers · choice

Every option has a cost.

A segmented control shows two to four options; tabs separate views; a switch is instant; a menu hides the long tail. The curve on the right is the price list.

Hick–Hyman · 1952 RT = a + b · log₂(n + 1)

Decision time grows with the number of equally likely options — slowly, but never for free.

5.5

Fields · intent

Ask once, clearly.

A field is a label, a control and a hint. Proximity does the grouping: 4px inside a field, 16px between fields. Focus is one soft halo. Nothing relies on placeholder text to name itself.

Proximity · Wertheimer 1923 gap in : gap out = 1 : 4

Things that sit close are read as one. The ratio does the grouping; no rule or box is needed.

5.6

Transient · confirmation

Speak once, then leave.

A tooltip explains on hover or focus, and hides on Escape. A toast confirms without stealing focus, lives 4.5 seconds, and stacks no more than three. Transient does not mean unreadable.

Reading rate · 200 wpm t = words ÷ 3.33 + 0.9 s

A message must outlast the time it takes to read it, plus the time to find it.

5.7

Live · proportion · motion

Motion, with a static twin.

Motion is physics or it is noise. Three springs move everything in truex; meters, rings, spinners and carets carry live state. Every motion has a still form, so reduced motion loses the animation and keeps the meaning.

Damped harmonic oscillator x″ + 2ζω x′ + ω² x = 0

ζ is honesty. Below 1 the thing overshoots and settles; at 1 it arrives without doubt.

Live · 07 / 09
Three springs · shared 480 ms axis

Curves are the exact step response of each spring, sampled into CSS linear(). Reduced motion jumps straight to the end: same destination, no journey.

5.8

States · non-happy paths

A state is a sentence.

Every list and panel needs three states beside the happy one: empty, loading and error. Each names what is happening, why, and the one action that moves forward. A dead end is a design error.

Peak–end rule · Kahneman 1993 memory ≈ (peak + end) ÷ 2

People remember the worst moment and the last one. An error is the peak; its exit is the end.

5.9

Contract · file

One file. No new tokens.

primitives.css is the application layer: sixteen primitives, one prefix, four foundations. It declares no new font, no raw hex, no new radius. States are CSS; JavaScript only moves data and focus.

Gall's law · 1975 complex ⟸ simple, working

A complex system that works grew from a simple system that worked. Sixteen parts, then patterns.
