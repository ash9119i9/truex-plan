2.1

The model

One loud colour, and a lot of quiet.

Colour has three jobs and one exception. Signal means interaction and live work. Status carries state. Identity is reserved for agents. Everything else — surfaces, ink, lines — is quiet chassis, and it is most of the interface.

Model · 01 / 09
01 · SignalOne hue

Signal blue

The only hue allowed to be loud. It marks what can be touched, what is selected and what is running now.

2.8

Rules & accessibility

The colour contract.

Ten rules, then the measured proof. Text needs 4.5:1, marks need 3:1, and no meaning may depend on hue alone — in any of the four contexts.

Rules · 08 / 09
01

One signal, one job.

Brand blue means interaction, selection, focus and live work. It is never a data series and never decoration.

02

One primary per surface.

A second signal-filled control makes the first one meaningless. Everything else is default, ghost or quiet.

03

Status keeps its glyph.

Hue + ink + soft, always with a glyph and a word. A colour-only state is not a state; it is a guess.

04

Identity is reserved.

Agents only, assigned in order of first appearance, never reused. There is no seventh hue.

05

Data is neutral.

Use the chart roles; r1–r4 is an ordered ramp, not a palette. Signal and status stay out of series.

06

Text 4.5, marks 3.

Measure every pair. Increased contrast is a fourth authored set, never a gamma or a CSS filter.

07

Dark is authored.

Never derive it with inversion, opacity or a blend. Every dark value is chosen and reviewed against its own surface.

08

No decorative colour.

Soft colours are state surfaces, not mood. The only textures are the page dot and hatch.

09

One glow, one halo.

signal-glow is the only translucent tone, for focus and live. No gradients, no glows as ornament.

10

No raw hex in components.

Components consume semantic tokens. Hex lives in color.css; if a value is missing, the system is missing a role.

One halo, one highlight.

  • ✓No meaning depends on hue alone.
  • ✓No raw hex outside color.css.

Accessible colour is not quieter colour. It is colour with a second channel: a glyph, a word, a shape, a position — something that survives when the hue does not.

2.9

Implementation

One file, one resolver.

Colour ships as color.css: four context blocks, semantic tokens, elevation and one focus halo. A pre-paint resolver chooses the effective context; components consume tokens and nothing else.

Build · 09 / 09

Two preferences, two effective attributes. The user's theme and contrast choices are resolved against the OS before first paint, then stored as data-eff-theme and data-eff-contrast on the root.

Fixed contexts are scoped. Any subtree with data-ctx receives a complete palette, which is how this page shows all four themes at once without iframes.

  • data-themeauto · light · dark — the choice.
  • data-eff-themelight · dark — the resolved surface.
  • data-contrastsystem · normal · more — the contrast choice.
  • data-eff-contrastnormal · more — the resolved contrast.
  • data-ctxlight · dark · light+ · dark+ — a pinned preview.
  • ✓color.css linked before page styles.
  • ✓The resolver runs before first paint; OS changes are listened for.
  • ✓Every component consumes tokens; no raw hex outside the palette.
  • ✓All four contexts reviewed; the ledger passes.
  • ✓Status glyphed, identity reserved, signal kept out of data.
  • ✓Focus uses one soft halo; selection uses one tint.

resolver · before first paint 
const scheme = matchMedia("(prefers-color-scheme: dark)");
const contrast = matchMedia("(prefers-contrast: more)");

const dark = theme === "dark"
  || (theme === "auto" && scheme.matches);
const more = contrastPref === "more"
  || (contrastPref === "system" && contrast.matches);

root.dataset.effTheme = dark ? "dark" : "light";
root.dataset.effContrast = more ? "more" : "normal";
