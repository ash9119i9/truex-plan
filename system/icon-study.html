The hand

A cut, a dot, nothing else.

A4

Scope

Approve the hand. Then we draw the set.

Five samples are enough to judge the cut, the dot, the weight and the silences. If the hand is right, the necessary set is drawn in one pass.

Scope · A4 / A4
Working principlesThe hand
  • 01
    One hand.

    24 grid, 1.75 stroke, round caps. No per-icon style, no second thickness.

  • 02
    One interruption.

    A cut, a gap or a socket; the rest is calm monoline.

  • 03
    Dots mean.

    Agent eyes, trace node, tool socket. A dot is never decoration.

  • 04
    Colour is inherited.

    CurrentColor by default; signal only for active and live. No identity in UI icons.

  • 05
    16 is the test.

    Draw at 24, approve at 16. If a detail dies at 16, it was not needed.
