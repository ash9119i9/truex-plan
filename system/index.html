1.7

Measure & rhythm

A line is a unit of reading.

Body copy stops at 42rem — the width at which a line still reads as one breath. Ledes get 46rem. Nothing is justified; nothing is centred past two lines.

1.8

Rules & accessibility

Ten rules. No exceptions.

The lock is only useful if it is enforced. These are the constraints a reviewer applies to every truex surface — and the accessibility contract underneath them.

Rules · 08 / 09
01

Use the role, not a size.

If it is not in the thirteen, it does not ship. Drift begins with one hand-tuned heading.

02

One serif phrase per surface.

At headline size, in italic, once. A second accent is a hierarchy problem, not a styling opportunity.

03

Mono never sets prose.

Geist Mono is for labels, values, time and code — anything scanned or aligned. Reading stays Bricolage.

04

Numbers are tabular.

Every figure uses tabular numerals with a slashed zero. Changing a digit must never move the column.

05

Body lines stop at 42rem.

The measure protects the return sweep. Ledes get 46rem; micro labels get a line, not a paragraph.

06

Uppercase lives in mono.

Headings are sentence case. All-caps is a property of micro labels, tracked +0.12em, never emphasis.

07

Heavy is display-only.

Bricolage at 760+ is for display and headings. Body never exceeds 500; UI controls sit at 600.

08

Optical size is a token.

opsz and wdth are assigned by role. They are the voice of the cut, not a per-screen effect.

09

No fake syntax.

No letterspacing on lowercase, no synthetic bold, no fake italic. font-synthesis: none is enforced.

10

Small has a floor.

11px is the metadata floor and 13px is the floor for anything essential. Body is 15px at 100%.

01 · Text scaling

The page scales, not the layout.

Every size is rem. At 200% this is a larger view of the same page — not a broken one.

03 · Loading

Loaded once, declared twice.

Google Fonts with preconnect and display=swap; every stack falls back to the platform.

--f-ui: "Bricolage Grotesque", ui-sans-serif, system-ui, sans-serif;
--f-serif: "Instrument Serif", ui-serif, Georgia, serif;
--f-mono: "Geist Mono", ui-monospace, "SF Mono", monospace;

All three families are SIL OFL 1.1. Self-host them for air-gapped deployments.

04 · Floors

Small has a floor.

  • ✓11px is the metadata floor; 13px for anything essential.
  • ✓Body is 15px; ledes are 17px at 100%.
  • ✓Never justify. Never centre past two lines.
  • ✓No text baked into images; lang is always declared.
  • ✓Line height is unitless; fallback metrics cannot collapse it.

200% is the test, not an edge case. Use the Type control in the bar and read this page again before shipping a new surface.

1.9

Implementation

One file, no new sizes.

The chapter ships as type.css: families, cuts, thirteen role classes and the measure. The role specimens on this page are set from it; the chapter shell only arranges them.

Build · 09 / 09

Use the role, not a raw size. Link type.css after your reset and apply a role class. Product code should never carry a font size that is not a token.

The optical cut is pinned. font-optical-sizing: none lets the declared opsz axis render instead of the browser's automatic guess. That is why display reads narrow and text stays open.
