The continuous hand

No more 45° cuts.

The first hand was a style study: a bevel, a notch, a forced interruption per glyph. This one is derived from the same K2 superellipse as the surfaces, a 24 grid and the perceptual archetype each glyph carries. No bevels. One hand.

You were right. The old set exempted the glyphs from the corner foundation. This revision removes the exemption, not the clarity.
